# kr8tiv-io · org configuration

This repo holds organisation-level config for **[kr8tiv-io](https://github.com/kr8tiv-io)** — the marketing arm of the [kr8tiv](https://github.com/kr8tiv-ai) ecosystem.

The good stuff lives in **[`profile/README.md`](./profile/README.md)** — that's the file GitHub renders on **[github.com/kr8tiv-io](https://github.com/kr8tiv-io)**.

---

## What's in here

- 🖼 **`profile/README.md`** — the public org profile (services, portfolio, ecosystem)
- 🎞 **`profile/banner.gif`** — the looping hero animation rendered above the org bio

## Why a separate `.github` repo?

GitHub uses a special repo named `.github` (with a `profile/README.md` inside) to render markdown on the org landing page. This is that repo.
